= The A2ML files removed from panic-attack on 2026-11-14

The owner approved moving panic-attack off A2ML on 2026-11-14, the way
hypatia did (hyperpolymath/hypatia#1113). Every `.a2ml` file in panic-attack
is translated into deed form where a mapping spec says it translates, every
reader is moved off it, and the file is deleted. The mapping specs are in
standards `1-formats/deed/mappings/`; a field a spec does not list does not
translate and was dropped, not re-homed. Files with no mapping spec were
deleted (A7 section 11, ruling Q7).

This record lists each removed file, what it was, and where its content
went. The contents are not copied here. Git history keeps them. To read one,
use its blob id, or read its path at the last commit that held it:

[source,bash]
----
git cat-file -p <blob id>
git show 81eee5400c785f5e633f8983610e57c43295d3ed:<path>
----

Size is in bytes. The sha256 is of the file as it was tracked.

== Readers moved

* `src/a2ml/mod.rs`: the AI manifest is read deed first. `0-AI-MANIFEST.deed`
  (a pointer-only `repo-deed`, parsed with `src/deed.rs`) when it exists;
  the legacy `0-AI-MANIFEST.a2ml` and `AI.a2ml` only as a fallback for
  repositories that have not moved. A deed manifest carries no report
  settings. `panic-attack manifest` and `panic-attack diagnostics` use the
  same order.
* `src/diagnostics.rs`: panicbot directives are looked for as the
  `(bot-directives (bot :name panicbot …))` clause of the repo deed
  (`agentic-neurosym-playbook-to-repo-deed.adoc` §6), not at the stale
  `.machine_readable/bot_directives/panicbot.scm`. None declared means the
  full suite (owner ruling 2026-11-13).
* `src/assail/classifications.rs` was already deed first (#295); unchanged.
* `.machine_readable/MUST.contractile`, `contractile.just`, `bust.ncl`,
  `.claude/CLAUDE.md`, `.github/CONTRIBUTING.md`, `QUICKSTART-DEV.adoc` and
  the `scan-and-report.yml` comment point at the deeds.
