== Installation entrypoint follow-up

Justfile because `ci` is duplicated; `fmt-check` is duplicated too. Neither
recipe is suppressed: the fuller CI dependency list and all-target formatting
check remain. `just assail` no longer converts scanner failures into a
successful "not found" message. Installation creates the user-local bin directory
and builds with the lockfile enforced.

availability, not minimum-version compliance or successful compilation.
Bootstrap recipe selection uses `just --show`; a failed fallback doctor stops
setup before its success report. The user quickstart documents actual commands
and separates the default Rust MSRV from optional GUI requirements.
